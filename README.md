# ⌚ A clock stuff hiding in an SVG
> *A tiny Flask thing that turns your local time into a growing rectangle.*

Tried making a clock with no JavaScript. Flask sneaks the time into an SVG's width.  
My CSS-only Pen reads that width using the [view-timeline](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Properties/view-timeline) feature, then keeps the seconds ticking.  
Super silly; a bit of CSS magic; exactly why I made it.

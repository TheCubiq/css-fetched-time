# ⌚ A clock hiding in an SVG

> *A tiny Flask thing that turns your local time into a growing rectangle.*

Tried making a clock with no JavaScript, Flask sneaks the time into an SVG's width. My CSS-only Pen reads that width using a view timeline, then keeps the seconds ticking.
Super silly; a bit of CSS voodoo; exactly why I made it.

> [!WARNING]
> Uses view timeline wizardry, so only works in Chromium-based browsers as of today, sorry furryfox users..
